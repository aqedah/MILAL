Reinoud Henri Oosting,
Walls of Zion and Ruins of Jerusalem:
A Corpus-Linguistic View on the Participant Zion/Jerusalem in Isaiah 40–55

주요 참조 부분:

- Chapter 1: On Method

중요:

MILAL은 Oosting의 이사야 40–55 분석 전체를 구현하지 않습니다.

Oosting에게서 선택적으로 수용할 것은:

1. clause relation 판정 전에 clause-internal valency structure를 검토하는 원칙
2. 분리된 clause_atoms가 하나의 valency pattern을 이루는지 검증하는 원칙
3. 동일/유사한 구문을 히브리 성서 전체 corpus에서 검색하여 linguistic regularity를 검증하는 원칙
4. 관찰된 syntactic pattern을 성급하게 일반화하지 않고 실제 형식대로 우선 등록하는 원칙
5. syntax → discourse structure → participant analysis라는 단계적 해석 순서
6. Masoretic accentuation을 primary structure signal이 아니라 secondary adjudication evidence로 사용하는 원칙
7. text as it stands를 먼저 기술하고, reconstruction을 분석 시작점으로 삼지 않는 원칙

다음은 그대로 가져오지 않습니다:

- Isaiah 40–55 specific valency conclusions
- Zion/Jerusalem participant conclusions
- Isaiah-specific textual hierarchy
- 특정 Masoretic accent decision
- 특정 본문 emendation 판단
- 특정 participle interpretation

O2. Critical architecture correction:
VALENCY before CLAUSE RELATION
==================================================

현재 central engine 순서를 다음과 같이 수정하세요:

RAW BHSA FEATURES
→ CLAUSE_ATOM INVENTORY
→ CLAUSE-INTERNAL VALENCY / BINDING ANALYSIS
→ CLAUSE CONSTRUCTION / CONSTITUTION CANDIDATES
→ EXACT CONSTRUCTION SIGNATURE
→ PRECEDING CLAUSE CANDIDATES
→ RELATION GRAMMAR
→ PROVISIONAL HIERARCHY

핵심 원칙:

두 clause_atoms가 서로 떨어져 있다고 해서
자동으로 서로 다른 clause relations를 이루는 것은 아닙니다.

먼저 다음을 물어야 합니다:

DO THESE CLAUSE ATOMS BELONG TO ONE CLAUSE
BECAUSE THEY COMPLETE ONE VALENCY PATTERN?

이 검사를 relation grammar보다 먼저 수행하세요.

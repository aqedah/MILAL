# Researcher clarification — Q1.2

Confirmed by the researcher in this task:

`BARE_SPEECH_FORMULA_ALONE_CANNOT_QUALIFY_BINDING`, not
`SPEECH_FORMULA_REMOVED_FROM_CONFIGURATION_PROFILE`.

Positive configuration binding requires independently bounded configurations,
internal position correspondence, and at least one independently observable
pair-binding witness:

- explicit lexical anchor in corresponding grammatical roles;
- temporal frame correspondence;
- locative frame correspondence.

Time/location witnesses must record source frame, target frame, shared structural
basis, formal difference and provenance. Generic TIME_PRESENT or LOCATION_PRESENT
is insufficient. Without these witnesses record SAME_CONFIGURATION_FAMILY;
do not upgrade to QUALIFIED_CONFIGURATION or ESTABLISHED_PARALLEL_CONFIGURATION.

Grammatical-role correspondence concerns function (subject to subject, locative
to locative, complement to complement), not whole-phrase token identity.
Family/profile names remain data-derived, with no book/control-specific names.

This is a researcher-authorized MILAL executable contract, not a new quotation
from Jin, Walton, Bosman or Oosting.

## Two edges and complete partitions

LEFT_EDGE cut k=A; RIGHT_EDGE cut k=B+1. A cut is between indices k-1 and k,
including corpus beginning/end cuts. For each edge, partition **every** formal
occurrence into three exclusive, exhaustive sets:

- TERMINATES_BEFORE_OR_AT: y < k.
- CROSSES_EDGE: x < k <= y.
- BEGINS_AFTER_OR_AT: x >= k.

The first/third sets contain remote occurrences too, so they must not be read as
local beginnings/endings. Explicit `incident_formal_ids` subsets distinguish
immediate termination y=k-1, immediate beginning x=k, and all crossings.
Three rows per edge store full exact occurrence ID lists, without pruning.
Counts describe set cardinality only; there is no score, ranking or salience claim.
Formal crossings express positional/formal continuity only, never discourse continuity.

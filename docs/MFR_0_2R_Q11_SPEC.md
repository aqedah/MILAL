# MFR.0.2R-Q1.1 — Source-binding coverage review

Authority: [researcher request](MFR_0_2R_Q11_RESEARCHER_SOURCE.txt).
Baseline: `039284206418253d42f0998a6af05382dde511c8`.
This additive diagnostic stage consumes the exact Q1 and MFR.0.2R releases.
It does not run new qualification, change witnesses, create relations, resolve
human judgments, select a mother/hierarchy, or start H0.1.

## Source and identity contract

Verify both input ZIPs, CRCs, member manifests, and extracted file hashes.
Pin the existing 461 frozen files and 12 Q1 code/config/test/specification files.
Independently stream all raw pairs, original matches, Q1 qualification records
and row-hash crosswalks in lockstep. Compare the loaded qualified universe with
the qualifying rows; check outcomes/groups and recompute pivot witnesses using
the frozen symbolic-assignment semantics. Counts are regression assertions in
configuration, never source-binding conditions.

Read human decisions only after blind Job diagnostics are frozen. Preserve all
13 original decision objects and their hashes. External observations are loaded
only for the exact frozen fixture clause IDs, with all original feature receipts
verified against Q1. No external book inventory or new candidate universe is
created. Archive integrity scanning is distinct from semantic consumption of
control results. Q1.1 calls no qualification function: its blind phase decomposes
existing fixed units; the post-freeze phase reproduces existing source witnesses
and diagnoses their coverage.

## Fixed-unit sensitivity protocol

The population is **every original relation pair**, separately for Job and each
existing external scope. This is not all raw search pairs and not just pairs
already admitted by W-P01. Preserve pair-level vectors and denominator counts.

Keep Q1 units exactly as extracted: a clause and consecutive following clauses
directly native-linked to that opening, stopping at the first non-linked clause.
Measure five predicates without changing those units:

1. Both existing units contain more than one clause.
2. Their permitted explicit lexical NP witnesses share a lexeme.
3. A shared NP lexeme occurs at the same member offset and grammatical function.
4. Both have a non-speech predicate beyond a bare speech formula.
5. Complete clause-type, word lexeme/POS/vt/vs, and phrase function/type sequences
   are equal.

The conjunction must equal the frozen SB06 conjunction for every inspected pair.
The NP/position checks expose implications previously enforced by full signature
equality. They do not strengthen qualification. A sole failure means the other
four predicates pass. A joint failure means at least one other predicate fails.
The predicates are correlated: zero sole failures does not establish irrelevance.

Contiguity is measured as existing multi-clause-unit availability. This review
does not invent noncontiguous units, change root-link extraction, or claim a
counterfactual relation recovery count. All counts describe fixed-unit coverage.
The exact operational forms are conservative MILAL choices, not newly attributed
universal scholarly requirements.

## External review and larger units

Audit the five configured Numbers alternatives across four pairs, retaining
exact endpoint clause/atom/phrase/word observations, original rule definitions,
full available pair evidence, native-edge/path attempts, and SB06 failures.
Control IDs select diagnostic rows only after freeze; they never select rules.

For Bosman, reconstruct the same existing fixture edge set from frozen relation
checks. Expand factorized references with the frozen unit-query implementation.
Exact source/target/antecedent node identity does not resolve referential identity.
Keep the full conditional unit selector and graph, and retain assignment-dependent
paths as conditional evidence, not independent proof of the relation tested.

SB01–SB12 are all reviewed. Implemented adapters and currently used witnesses are
different concepts. An unsupported category name is not an executable mechanism
and not evidence that a specific control qualifies. All adapter details remain
GENERALIZED_FOR_MILAL; source citations and adoption distinctions from the frozen
grammar/layer implementations remain unchanged.

External non-retention categories may overlap. A denotes no original relation
available to retain, not a new human rejection. B denotes unresolved evidence;
C an unavailable adapter whose applicability still needs proof; D a conservative
operational subset that may be overrestrictive. None is automatically a false
negative. Machine-readable pair details preserve every existing control row.

## Gates and release

The required 23 gates operate on measured source comparisons, exact identities,
coverage arithmetic, AST policy checks, phase-order/file-freeze receipts,
current full regression, independent byte comparison and verified manifests.
Every gate has a negative evidence mutation; source predicates and policy checks
also have targeted negative fixtures. Full regression must have zero skips.

Both independent executions verify sources separately. Release finalization
occurs only after all deterministic files match. Final manifests and ZIP bytes
must match as well. Large results, PDFs, logs and input ZIPs stay outside Git.

Q1.1 may present up to three methodological options but must not select one.
Readiness is limited to the three researcher-authorized review states. No H0.1
readiness claim is permitted. The pending question is an independent witness
contract for configurations and containing-unit references, not a target count.

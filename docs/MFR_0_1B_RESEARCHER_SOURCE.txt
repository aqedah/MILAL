2. 핵심 방법론적 수정
==================================================

MARKER-FIRST는:

“모든 linguistic feature를 동일한 종류의 marker로 취급한다”

는 뜻이 아니다.

다음을 구별한다.

A.
PRIMARY_FORMAL_MARKER_CANDIDATE

본문에 실제 formal construction으로 나타나며
text-structuring marker 가능성을 독립적으로 검토할 수 있는 것.

B.
SUPPORT_SIGNAL

다른 marker의 계층력을 판단하는 데 쓰이는
participant/domain/configuration 변화 신호.

C.
COMPOSITE_MARKER_CANDIDATE

primary formal marker와 support signal이
같은 locus에서 동시에 나타나는 경우.

D.
LEXICAL_EVENT_CANDIDATE_REQUIRES_ROLE_AUDIT

특정 lexeme 때문에 marker 후보가 되었으나
그 lexical event가 실제 discourse/textual function인지
문맥적 역할을 더 판별해야 하는 경우.

이 분류는 hierarchy decision이 아니다.

5. 매우 중요 — cessation trigger를 다시 감사
==================================================

7. Cessation role generic criteria
==================================================

Reference-specific hard code 금지.

예를 들어 다음과 같은 linguistic evidence는
DISCOURSE/SPEECH cessation candidate를 지지할 수 있다.

- cessation predicate의 subject/object가
  word/speech/answer 관련 lexical item
- cessation predicate가
  answer/speak 행위의 infinitive/complement와 결합
- explicit speaker configuration
- preceding/following domain configuration이
  speech activity 변화와 관련

반대로 bodily/temporal/physical subject라고 해서
자동 REJECT하지 않는다.

단지:
NON_DISCOURSE_CESSATION_USAGE_CANDIDATE

로 분류 가능.

Human validation later.

9. 핵심 문제 — closure evidence의 독립성
==================================================

현재 closure 963쌍은 모두 coverage end evidence를 가진다.

그러나 MFR.0.1 coverage candidate가:

“next explicit cessation”

을 end candidate로 생성했다면,

그 coverage가 cessation target을 끝점으로 가진다는 사실은
독립적인 closure 증거가 아니다.

또한 그 coverage span에서 생성된 terminal nested evidence도
같은 upstream decision에서 파생되었다면
독립 증거가 아니다.

따라서:

COVERAGE_END
+
TERMINAL_NESTED

를 두 개의 독립 link로 세지 않는다.

==================================================
11. Independent evidence rule
==================================================

두 evidence가 동일 dependency root에서 파생되었다면
독립 증거 두 개로 취급하지 않는다.

예:

explicit cessation target
→ coverage end candidate
→ terminal nested evidence

는 하나의 dependency chain이다.

이를:

THREE SUPPORT TYPES

로 세면 FAIL.

대신:

ONE_CESSATION_DERIVED_CHAIN

으로 기록한다.

No score.

17. Configuration-level relation cases
==================================================

여러 pair row를 생성할 수 있다.

Human researcher에게 pair를 하나씩 묻지 않는다.

Generic하게:

overlapping or adjacent source markers
+
overlapping or adjacent target markers
+
shared sequence/configuration family
and/or strongly shared occurrence spans

을 이용하여:

CONFIGURATION_RELATION_CASE

를 만든다.

## Methodological interpretation

The additive layer separates global search evidence, structurally visible
competition, provisional source binding and referential identity. All 5,854
Q1.2 witnesses and their 1,329,190 original candidate records remain recoverable
as exact-byte copies. Original lexical/PNG search evidence is not erased.

Visibility derives only from native clause-internal grammar, preserved Q1.4
composite spans and exact typed native dependency endpoints. Overlapping spans
can supply a recorded shared-component path. No unrestricted graph closure,
chapter boundary, distance cutoff, ranking, human hierarchy or tested edge defines
domains. Supplemental domain candidates are distinguished from Q1.2 global
candidates; candidate reduction is not deletion or proof of exhaustive coverage.

Lexical NPs remain mentions. Unresolved pronominal antecedents remain visible
competitors instead of being discarded to manufacture uniqueness. Interrogative
forms retain a separate classification. Unique visible, grammatically supported
source binding has PROVISIONAL_UNIQUE_VISIBLE identity, not confirmed identity.
SB10 is explicitly evidence-only because lexical recurrence does not demonstrate
an independently marked anaphoric construction in this adapter.

No extended speech scope, addressee identity, standalone valency domain or bounded
temporal/locative domain is inferred from feature presence alone. Missing evidence
remains a coverage limitation. Every new relation requires an exact existing raw
pair, existing HYPOTACTIC grammar and the frozen qualifier's restrictions.

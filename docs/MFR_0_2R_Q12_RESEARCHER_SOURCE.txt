→ use same unit/configuration to prove relation

3. Source-grounded correction to SB06
==================================================

Current SB06 must NOT require universal:

IDENTICAL_FULL_SIGNATURE

4. Surface Configuration Profile
==================================================

For every clause / relevant clause group extract,
from already available BHSA/MILAL data:

CONFIGURATION_PROFILE:

- clause_type
- verbal_form / predicate morphology
- conjunction / syndesis
- explicit_subject_presence
- explicit_subject_lexeme if present
- complement structure
- phrase-function sequence
- phrase-type sequence
- pre-predicate constituent pattern
- locative adjunct structure
- temporal adjunct structure
- participant grammatical role
- speaker/addressee structure if surface-supported
- lexical anchor(s)
- suffix / pronominal morphology
- subordinate-marker structure
- direct-speech marker structure

Do not require every field to match.

Do not collapse these into a numeric score.

5. Observed configuration, not generalized identity
==================================================

Distinguish:

OBSERVED_CONFIGURATION

from

GENERALIZED_CONFIGURATION_PATTERN

Example:

Observed A:
DSF + LOC + LOC + TIME

Observed B:
DSF + LOC + TIME

They are not identical.

But both may instantiate a broader:

DSF_WITH_SPATIOTEMPORAL_FRAME

correspondence family.

Likewise:

ANSWER + AMR

and

ADD_SPEECH + TAKE_MASHAL + AMR

must remain distinct observed configurations
even if they share SPEECH_ONSET features.

No uncontrolled generalization.

==================================================
6. Independent configuration witness
==================================================

A configuration witness may qualify only if its defining
surface features are extracted independently of the
relation edge being tested.

Allowed sources:

- clause / atom morphology
- phrase functions
- phrase ordering
- lexemes
- explicit participant morphology
- explicit speech formula components
- time/place adjuncts
- explicit subordination
- independently established valency binding
- independently observable local clause sequence

Forbidden:

- provisional mother edge under test
- variant membership generated from that edge
- reachability requiring that edge
- human historical hierarchy
- expected control answer

Required field:

configuration_independence_status

Allowed:

INDEPENDENT_SURFACE
INDEPENDENT_VALENCY
DEPENDENT_ON_TESTED_RELATION
UNRESOLVED

Only first two can positively qualify SB06/SB11.

8. Corresponding variant
==================================================

CORRESPONDING_VARIANT means:

same structural family/function is formally observable,
but realization is not identical.

Example types:

- one vs two locative adjuncts
- explicit vs pronominalized participant
- shared construction with an additional time phrase
- same speech formula frame with an additional constituent
- same clause sequence with one embedded subordinate clause

Every CORRESPONDING_VARIANT must state:

source_observation
target_observation
shared_configuration_basis
difference
provenance

No semantic-only correspondence.

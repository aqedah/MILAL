중요:
이번 작업은 “진규상의 방법론 전체를 구현”하는 것이 아니다.

MILAL은 진규상이 제시한 방법 가운데 다음을 수용한다.

1. bottom-up linguistic inventory
2. form-to-function ordering
3. preceding clause candidate search
4. paratactic / hypotactic relation grammar
5. whole-hierarchy context에 의한 relation 재검토
6. 동일 syntactic pattern이 서로 다른 textual level에서
   서로 다른 기능을 가질 수 있다는 원칙
7. 복수의 syntactically persuasive hierarchy가 가능하다는 원칙

MILAL은 이에 다음을 추가한다.

1. 모든 candidate와 evidence provenance 보존
2. blind / human separation
3. relation alternatives 보존
4. evidence dependency 추적
5. deterministic rerun
6. typed non-hierarchical relations 보존
7. human adjudication history
8. 동일 데이터에서 다른 연구자가 다른 구조를 선택할 수 있는
   판단 경로의 재현 가능성

==================================================
0. 가장 중요한 수정
==================================================

기존 MFR의 중심 순서:

MARKER
→ FAMILY
→ FORCE
→ RELATION

을 hierarchy discovery의 주엔진으로 사용하지 않는다.

marker / family / signature는
candidate discovery를 돕는 index와 evidence로 보존한다.

새 central engine은:

FULL LINGUISTIC INVENTORY
        ↓
FOLLOWING CLAUSE
        ↓
PLAUSIBLE PRECEDING CLAUSE CANDIDATES
        ↓
EXECUTABLE RELATION GRAMMAR
        ↓
EVIDENCE MATRIX
        ↓
PARATAXIS / HYPOTAXIS / ALTERNATIVES
        ↓
PROVISIONAL HIERARCHY
        ↓
GLOBAL COMPATIBILITY
        ↓
VARIANT RELATIONS / VARIANT HIERARCHIES
        ↓
HUMAN ADJUDICATION

이다.

==================================================
2. CLAUSE TYPE와 FUNCTION을 분리
==================================================

매우 중요.

다음을 hard-code하지 않는다.

WayX = 항상 main narrative line
WXQt = 항상 antecedent information
Wayhi+Time = 항상 embedded narrative line

진규상도 동일 clause type이 서로 다른 textual level에서
다른 기능을 가질 수 있음을 전제로 한다.

따라서 schema를 분리:

clause_type
functional_role_candidate
adjudicated_function

예:

clause_type = WayX

possible functional roles:
- MAIN_NARRATIVE_LINE
- EMBEDDED_NARRATIVE_LINE
- PARTICIPANT_INTERPLAY
- PARAGRAPH_FRAME
- OTHER

기능은 relation/context에서 판정.

==================================================
24. Hard vs soft conflict
==================================================

HARD_CONFLICT examples:

- one accepted hypotactic daughter would have two mothers
  in the same hierarchy variant
- direct logical contradiction in relation assignment
- graph cycle in mother-daughter hierarchy

SOFT_CONFLICT examples:

- candidate competes with another strong parallel relation
- candidate requires different textual-level interpretation
- candidate changes placement of intervening clauses

Soft conflict must remain human-reviewable.

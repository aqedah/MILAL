# Proposed graph invariants

CONTRACT_PROPOSAL. Researcher review is pending; no R4.4 consumer is implemented.

- I1. No fabricated/default textual parent. Retain explicit parent IDs only.
- I2. Current non-textual composition groups cannot be direct textual parents.
  A separately approved retyping would require a new versioned adjudication;
  it has not happened. Continuation into a human-supplied scope is not CHILD_OF.
- I3. Technical navigation creates no analytical relation. JOB_BOOK and its
  historical 57 connectivity links stay outside the analytical hierarchy.
- I4. Explicit negative constraints are records; absence of an edge is not a
  negative finding. QA negative-control PASS is also not a human negative edge.
- I5. Same-level relations require no explicitly represented common parent.
  Preserve stored reciprocal siblings without manufacturing inverse edges.
- I6. Historical UNRESOLVED and human parent-not-required can coexist with
  false edge resolution. Necessity completion does not complete a tree.
- I7. No layer collapse. In particular TEXTUAL_SAME_LEVEL differs from
  COMPOSITION_GROUPING peers; transitions differ from overlays and membership.
- I8. Every accepted node/relation retains exact source receipts and all
  originating evidence/judgment/addendum chains. Technical IDs may correctly
  have no human author; missing human IDs must never be fabricated.
- I9. Role alias is not a second textual unit. Keep alias and canonical IDs,
  historical functions and explicit crosswalk, without deleting either record.
- I10. A future overlay extension is append-only relative to frozen lower
  layers. Endpoint union supports explicit node IDs, reference pairs and scope
  expressions. The participant-arc idea remains a future-scope document;
  extensibility tests inspect the schema and unchanged lower-layer bytes and
  create no hypothetical research relation.
- I11. Validate cycles according to relation semantics. Only explicit
  CHILD_OF/HIERARCHICALLY_ABOVE participate in parent-cycle checks. Historical
  sibling reciprocal arcs are valid; transition self-anchors are not parent
  cycles. A composition-membership DAG check, if approved, is separate and
  excludes composition peers. No generic heterogeneous directed-tree test.

The dry-run exercises the existing three explicit hierarchy edges and reciprocal
sibling records. Tests add a deliberately invalid parent cycle only to a copied
test object to demonstrate rejection; this never enters a research artifact.
R4.3's at-most-one asserted parent guard is documented; this audit does not
adjudicate a broader cardinality policy or impose an exactly-one requirement.

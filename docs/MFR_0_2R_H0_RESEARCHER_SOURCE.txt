1. Preserve the complete MFR.0.2R universe
==================================================

MFR.0.2R에서 생성된 모든 candidate pair를 그대로 보존한다.

기존 raw/candidate outputs를 변경하거나 삭제하지 않는다.

각 candidate에 새 필드만 추가하거나

==================================================
2. Review eligibility classes
==================================================

모든 candidate를 다음 네 범주 가운데 하나로 분류한다.

A. RELATION_ELIGIBLE

실제 HYPOTACTIC / PARATACTIC / MULTIPLE relation candidate로
인간의 판단이 필요한 후보.

B. CONFIGURATION_ELIGIBLE

개별 mother edge 여부와 별개로
반복 configuration, global compatibility,
variant hierarchy, blocking 또는 structural competition에
직접 참여하는 후보.

C. EVIDENCE_ONLY

형식, 시간, 장소, 참여자, 참조, lexical,
corpus analogue, prosodic correspondence 등의 증거는 있으나
현재 relation grammar상 hierarchy relation 후보가 아닌 경우.

D. INSUFFICIENT

현재 자료에서 적극적인 relation/configuration competition이 없는 경우.

Important:

EVIDENCE_ONLY와 INSUFFICIENT도 삭제하지 않는다.
단지 기본 human review packet에서는 제외한다.

==================================================
3. RELATION_ELIGIBLE criteria
==================================================

RELATION_ELIGIBLE은 다음 중 하나 이상을 충족해야 한다.

R1.
existing candidate_relation =
HYPOTACTIC

R2.
existing candidate_relation =
PARATACTIC

R3.
existing candidate_relation =
MULTIPLE

R4.
둘 이상의 source family rule이
같은 target/source pair에 대해
서로 다른 hierarchy relation을 제안함

예:
Jin → HYPOTACTIC
Walton → PARATACTIC prior

R5.
candidate mother competition에 직접 참여함

즉:
동일 target에 대해
2개 이상의 plausible hierarchy candidate가 존재

R6.
relation이
RELATION_DEFERRED_PENDING_CLAUSE_BINDING
또는 equivalent unresolved structural status

R7.
candidate relation을 선택할 경우
global hierarchy configuration이 달라짐

Important:

formal similarity alone
→ RELATION_ELIGIBLE 아님

lexical repetition alone
→ RELATION_ELIGIBLE 아님

time match alone
→ RELATION_ELIGIBLE 아님

participant match alone
→ RELATION_ELIGIBLE 아님

==================================================
4. CONFIGURATION_ELIGIBLE criteria
==================================================

다음은 configuration-level review 대상으로 분류한다.

C1.
candidate가 existing repeated multi-clause configuration에 참여

C2.
candidate가 global compatibility conflict를 발생

C3.
candidate가 parallel chain의 형성 / 해체에 영향을 줌

C4.
candidate가 alternative hierarchy variant component에 포함

C5.
candidate가 blocking 관계의 원인이 됨

C6.
candidate를 선택하면
다른 candidate의 mother assignment가 바뀜

C7.
candidate가 MFR.0.2A의 13개 configuration case와 직접 관련

C8.
same-pattern / different-level 판단에 영향을 줌

==================================================
5. EVIDENCE_ONLY criteria
==================================================

다음과 같은 후보는 보존하되
기본 human review에서는 제외한다.

- FORMAL_ONLY
- lexical correspondence only
- temporal correspondence only
- location correspondence only
- participant correspondence only
- reference correspondence only
- domain correspondence only
- corpus analogue only
- prosodic correspondence only

단,
위 증거가 relation rule 또는
configuration competition과 결합되면
RELATION_ELIGIBLE 또는 CONFIGURATION_ELIGIBLE로 승격한다.

==================================================
6. INSUFFICIENT handling
==================================================

INSUFFICIENT candidate는:

- raw universe에 그대로 남긴다.
- human packet에서는 기본 제외한다.
- count / statistics / audit에는 포함한다.

No deletion.
No pruning.

==================================================
7. Target-level review eligibility
==================================================

candidate뿐 아니라 target도 분류한다.

TARGET_REVIEW_REQUIRED
TARGET_REVIEW_OPTIONAL
TARGET_ARCHIVE_ONLY

TARGET_REVIEW_REQUIRED if:

T1.
2개 이상의 RELATION_ELIGIBLE candidate가 있음

T2.
HYPOTACTIC vs PARATACTIC competition 존재

T3.
MULTIPLE relation candidate 존재

T4.
global configuration conflict 존재

T5.
variant component에 포함

T6.
MFR.0.2A 13건의 target 또는 직접 경쟁 후보

T7.
valency/clause-binding unresolved 상태

T8.
multi-source analytic conflict 존재

T9.
현재 provisional human decision의 재검증이 필요함

==================================================
9. Human review tiers
==================================================

review packet을 세 단계로 나눈다.

TIER_1 — IMMEDIATE REVALIDATION

포함:

- MFR.0.2A의 13건
- 그 target의 실제 RELATION_ELIGIBLE competing candidates
- direct global conflict / variant cases
- current provisional judgment와 충돌하는 새 candidate

TIER_2 — STRUCTURAL COMPETITION

포함:

- 2+ plausible mother candidates
- HYPOTACTIC/PARATACTIC competition
- multi-source conflict
- valency-related deferred relation
- hierarchy variant component

TIER_3 — LATER REVIEW

포함:

- relation candidate는 있으나
  현재 major configuration에 직접 영향을 주지 않는 경우

EVIDENCE_ONLY / INSUFFICIENT는
기본적으로 human review tier에 넣지 않는다.

18. Long-distance candidates
==================================================

Long-distance라는 이유만으로 제외하지 않는다.

그러나 long-distance candidate가:

- relation rule 없음
- configuration relation 없음
- evidence only

이면 기본 review packet에서는 제외한다.

반대로:

long-distance
+
relation grammar
또는
strong participant/reference/configuration evidence
또는
global effect

이면 review eligible로 유지한다.

5. Evidence bundle types
==================================================

각 bundle을 다음 descriptive category 중 하나 이상으로 분류한다.

REPEATED_OCCURRENCE_BUNDLE
- marker occurrence >= 2

SINGLETON_EXPLICIT_BUNDLE
- occurrence 1
- explicit formal construction이 marker로 포착됨
  예:
  EXPLICIT_CESSATION
  OPEN_MOUTH_CONSTRUCTION
  ADD_PROVERB_SPEECH
  기타 generic explicit construction

SINGLETON_GENERIC_BUNDLE
- occurrence 1
- 여러 signature resolution이 동일 marker를 기술하지만
  반복 관계 자체는 없음

MULTI_RESOLUTION_BUNDLE
- 동일 marker set을 둘 이상의 family type이 기술

SINGLE_RESOLUTION_BUNDLE
- 한 family representation만 존재

Do not treat these as quality rankings.

14. Closure source eligibility evidence
==================================================

CLOSURE_LINK_ONSET_FORM
- source marker가 speech/narrative/onset-like formal construction evidence를 가짐

CLOSURE_LINK_COVERAGE_END
- source의 coverage candidate 중 target cessation anchor에서 끝나는 것이 있음

CLOSURE_LINK_FORMAL_FAMILY
- source/target 사이에 relevant formula/sequence relation 존재

CLOSURE_LINK_PARTICIPANT
- source 이후의 participant configuration과 cessation까지의 continuity

CLOSURE_LINK_DOMAIN
- source와 cessation 사이 domain configuration compatibility

CLOSURE_LINK_NESTED_CONFIGURATION
- source coverage에 cessation marker가 terminal nested marker로 위치

CLOSURE_LINK_NONE
- 위 evidence가 없음

35. Important — do not ask human to validate signatures mechanically
==================================================

Human researcher should not have to decide separately:

“Is JMF01234 valid?”
“Is JMF04567 valid?”

when both describe the same marker occurrence set
at different signature resolution.

The human question is:

“What linguistic construction/family is actually represented by this
bundle of multi-resolution evidence?”

This distinction is essential.

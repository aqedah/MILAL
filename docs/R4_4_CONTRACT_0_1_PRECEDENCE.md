# Proposed precedence and conflict rules

CONTRACT_PROPOSAL. No new human judgment or analytical relation is authorized.

PRESERVE_HISTORY + USE_LATEST_APPLICABLE_HUMAN_DECISION_FOR_ACTIVE_REPRESENTATION.
"Applicable" requires exact object/candidate identity, explicit source links,
the same question and compatible dimension. Shared location or a later date
alone does not establish precedence. Historical records are never overwritten.

1. Historical observation → linked human adjudication: retain both, preserve
   evidence IDs, original statuses, record locators and artifact hashes. Use only
   the explicitly supplied accepted decision for that question. HSA2-F closure
   decisions are an existing example, not an invitation to resolve candidates.
2. Historical candidate → HUMAN_DEFERRED: retain candidate UNRESOLVED and a
   separate human decision state. ANA-Q3 does not become accepted, deleted,
   rejected or an empty NULL. No accepted overlay edge is emitted for it.
3. Historical parent UNRESOLVED → parent not required: keep both. Necessity is
   a representation requirement, not a discovered parent or NO_PARENT assertion.
   All 57 historical rows coexist with false additional review and false edge
   resolution. LAYER.0.2 changes the active necessity queue, not parent truth.
4. Positive and negative records in different dimensions coexist. For 31:40,
   local closure to 29:1, no direct closure to 27:1 and termination of the
   POST_DIALOGUE_JOB group are distinct claims. Contextual overlay at 37:24/38:1
   does not override a negative direct-parent or response-antecedent constraint.
5. A same-object, same-dimension contradiction without explicit supersession
   is AMBIGUOUS_SCHEMA/researcher review; do not select a preferred statement
   using timestamp, topology, lexical similarity or proximity.
6. Technical links never outrank analytical evidence. Missing analytical edges
   remain absent, not implicit negatives and not synthetic root attachments.
7. A role alias remains an explicitly linked record, not a second unit.
   Canonical speech and all historical role functions remain independently
   traceable. Do not rewrite existing edge endpoints to silently merge aliases.

Status axes are independent: adjudication_status, human_decision_status,
historical_status, necessity_status, review_status, frozen_status and future_scope_status.
SUPERSEDED_BY_LATER_ADJUDICATION is a scoped provenance relationship, not a
blanket mutation of an entire old record. No such new analytical relationship
is generated by this dry-run. Unrecorded optional fields use NOT_RECORDED
presence metadata; false, empty, NOT_APPLICABLE and UNRESOLVED remain distinct.

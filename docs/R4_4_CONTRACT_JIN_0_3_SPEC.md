# JIN.0.3 — contextual relation consolidation

Authority: [exact researcher request](R4_4_CONTRACT_JIN_0_3_RESEARCHER_SOURCE.txt).
Baseline: `4455716793eb6e015b309ccfa5106c6c19a5bf24`. All JIN.0.2 cores,
pairwise outputs and historical judgments remain frozen. This stage authorizes
synthetic/real contextual execution, independent rerun, commit and normal push.
It does not authorize adjudication, a mother selection or the R4.4 consumer.

## Method

“Pairwise correspondence is evidence, not textual hierarchy.”

“A clause pair may be formally parallel while its wider configurations occupy different textual levels.”

“Macro projection requires contextual evidence beyond a single matching formula where such evidence is available.”

“Clause-internal hypotaxis must not be mistaken for a macro textual mother relation.”

“Human adjudication operates on consolidated contextual cases, not on every mechanically eligible clause pair.”

Context flags describe available raw configurations; neither exactness nor
divergence establishes an accepted paratactic/hypotactic relation. Operational
rules below are inspectable evidence classifications, not a newly inferred
historical Jin classifier. No numerical similarity, weighting, winner or cap.

## Neutral membership and windows

Locus membership is exactly the frozen JT inventory's clause IDs, including every
overlapping clause in the source verse. No nearest-locus or human-unit expansion.
An unanchored clause receives a source-qualified JL+clause-ID identity; it is not
silently attached to an HSA node. All explicit memberships are retained.

Each focal clause has five separate windows: fixed [-3, focal, +3], complete
overlapping source verse(s), maximal contiguous same-known-domain run, raw formula
continuation through adjacent say (within the upstream three-clause context),
and a descriptive forward run until explicit participant-surface configuration
changes. Unknown domain ? yields a singleton domain run. Book bounds clip windows.
Fixed and adaptive records never overwrite each other; raw domain transitions,
source nodes/atoms, surfaces, references and the participant-change stop node remain.
The participant run does not infer coreference across implicit/absent subjects.
Each window also records the next raw formula onset's exact clause, reference,
surface and clause distance within the book, without changing the window. This
generic descriptive probe exposes response/formula proximity outside +3; distance
is never a relation score or a classification input.

Ordered signatures expose clause types; verbs with lexeme/stem/form/PNG; explicit
subject lexemes or unresolved implicit PNG; phrase layout; raw domain; formula
atoms/type; explicit participant surfaces; Time/Loca lexemes; pronouns and suffixes.
Surface recurrence/change flags are descriptive, not participant identity claims.

## Categorical configuration rules

Core clause configuration compares type, verbal tuples, subject sequence, phrase
layout, known domain, formula atoms, participant surfaces and temporal/locative
lexemes. Exact equality with known domain is MATCH. Otherwise matching verbal
tuples or matching type plus phrase layout is PARTIAL; otherwise DIFFERENT.
Out-of-book comparisons are NOT_AVAILABLE. No empty/unknown domain creates exactness.
Focal formula correspondence may be MATCH from shared formula atoms plus matching
verbal tuples; the full surrounding/core signatures still expose differences.

For each offset -3..+3, compare aligned ordered clauses. Compare each signature
dimension independently across the seven positions. An ordered sequence is MATCH
when equal, PARTIAL when at least one corresponding available position agrees,
DIFFERENT when none agrees, NOT_AVAILABLE when a side has no data. Counts never
select a relation. Generic following-length 1, 2 and 3 results are recorded.

- EXACT_CONFIGURATION_CORRESPONDENCE: focal MATCH and following 1/2/3 all MATCH.
- CONFIGURATION_CONTRAST: focal MATCH and following 1/2/3 all DIFFERENT.
- PARTIAL_CONFIGURATION_CORRESPONDENCE: a following clause MATCH or all three
  preceding clauses MATCH, but not the exact condition. Different focal forms
  can therefore have matching wider configurations.
- FOCAL_ONLY_CORRESPONDENCE: focal MATCH without the above wider match.
- NO_CONTEXTUAL_CORRESPONDENCE: none of those bundles.

Preceding/following divergence flags retain any aligned DIFFERENT position even
when the overall configuration is partial. They never flip the pairwise label.

## Scope and projection

Scope A / NOT_PROJECTABLE_CLAUSE_INTERNAL requires supported hypotaxis, shared
neutral locus and distance at most three clause positions. Local dependency
types separately report relative, infinitive, formula-internal, same-verse,
cross-verse-local or cross-locus evidence. H1/H2 use frozen upstream rule bundles.

Scope B / POSSIBLE_LOCAL_UNIT_PROJECTION covers a shared locus or a local pair
whose endpoints do not both align to distinct neutral-locus initial clauses.
Thus a pair ending inside a target's clause bundle is not automatically its
macro-mother relation. Scope C / POSSIBLE_CROSS_LOCUS_PROJECTION requires distinct
neutral loci with both focal endpoints at their raw initial clauses. Scope D /
POSSIBLE_MACRO_PROJECTION additionally requires focal and following 1/2 MATCH.
Scope E / INSUFFICIENT_FOR_PROJECTION retains other real evidence. These are
conservative projection checks, not a proof that later/non-initial evidence
could never support a macro relation in a future explicitly authorized audit.

The separate cross_locus flag is literal neutral-membership separation, so it
may be true even for Scope B local boundary evidence. Macro mother pool includes
only supported hypotaxis with non-internal scope and possible cross/macro
projection. No mother is selected. All candidate types are UNADJUDICATED.

## Lossless consolidation and archive

Primary pool is the actual 80 parataxis plus 149 hypotaxis hypotheses. Case key:
neutral locus endpoints + relation family + projection scope. Parataxis uses
canonical neutral ordering; hypotaxis keeps earlier candidate→later daughter
direction. Every source pair/evidence/hypothesis and original direction remains
in membership records. No similarity-based identity merge is used.

13,126 insufficient rows remain with their full source pair/hypothesis in archive
08 and default_human_review=false. C1 may attach same-locus-pair, nearby fixed
context evidence as a separately marked auxiliary; it never becomes a new default
case. All neutral focal-head combinations and exact target-clause pairs are
contextualized generically before C2 so C2 can show historical controls without
feeding their human labels into C1.

C2 may resurface insufficient evidence only through exact historical pair IDs
or the supported-context auxiliary mapping. It groups all historical SAME_LEVEL
and mother comparisons by neutral endpoints; original judgments are unchanged.
The historical 13,344-case list is preserved, not reused as the default queue.
No arbitrary size cap is applied. Computed review count must be less than the
upstream unique-pair review population; reduction ratio is QA only.

## C2 comparison, review and placement

Pairwise conflict is softened descriptively when matching focal form coexists
with observed preceding/following divergence, otherwise preserved. This does not
accept the human relation. Exact repeated context accompanying expected pairwise
support is CONTEXT_SUPPORTS_HUMAN_RELATION; partial context remains partial;
absent/insufficient context stays so. Opposite/competing evidence stays visible.
The source pairwise comparison and complete original human record remain linked.

Supported cases with possible cross/macro projection enter REVIEW_B; contextual
contrast or unresolved/local macro projection enters REVIEW_A for clarification.
Clause-internal-only cases enter REVIEW_C appendix, not the default decision list.
Historical partial/conflict/insufficient rows are grouped post-freeze in REVIEW_A;
all 98 SAME_LEVEL records have one machine comparison row and grouped presentation.
REVIEW_D denotes archive-only evidence. Buckets and evidence-tier tags are not
scores or ranks. The default A/B/C/D packet requests locus-level adjudication;
section E summarizes clause-internal evidence and section F summarizes the archive.

CP proposals use contextual candidates: macro hypo, macro para, para with contrast,
internal-only, descriptive cessation review, insufficient macro placement, or
competing macro types. Cessation uses raw CBT/TMM/KLH lexemes, never historical
transition labels. Old JP proposals remain PAIRWISE_ONLY_PLACEMENT_PROPOSAL;
differences are marked CONTEXT_REFINEMENT_DIFFERENCE without automatic supersession.

Canonical REVIEW_FIELDS are imported only in C2 and extended with requested
relation/macro-projection fields. Only UNREVIEWED is prefilled. Special panels
show all 2:11 and 32:1 hypotheses and all three old mother judgments; 38:1/40:1/
40:6 also has a three-way raw panel. Root and participant identity stay undecided.

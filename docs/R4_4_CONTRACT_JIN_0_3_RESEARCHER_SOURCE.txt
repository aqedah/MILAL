==================================================
0. 이번 단계의 목적
==================================================

JIN.0.2는 성공적으로 clause-pair 후보를 blind discovery했다.

그러나:

13,344개의 unique clause-pair review case를
연구자가 하나씩 판정하도록 넘기는 것은 방법론적으로도,
실행 가능성 측면에서도 부적절하다.

또한 pairwise formal correspondence는
macro/textual relation을 충분히 설명하지 못할 수 있다.

대표적 사례:

1:6 ↔ 1:13
- 동일/유사한 ויהי היום opening
- pairwise formal correspondence가 강할 수 있음
BUT
- 1:6 뒤에는 בני האלהים / להתיצב / השטן / divine dialogue 배열이 이어짐
- 1:13에는 동일 후속 configuration이 없음

38:1 ↔ 40:1
- 둘 다 ויען יהוה את איוב ... ויאמר formula
- pairwise formal correspondence가 강함
BUT
- surrounding speech-response configuration과 textual position은 다를 수 있음

따라서 이번 단계의 핵심은:

CLAUSE_PAIR_EVIDENCE
        ↓
CONTEXT_BUNDLE
        ↓
LOCUS_RELATION_CASE
        ↓
MACRO_PROJECTION_STATUS
        ↓
HUMAN_REVIEW_PACKET

이다.

중요:

이번 단계도 human adjudication이 아니다.

==================================================
4. relation scope를 먼저 분류
==================================================

각 supported pair에 대해 blind하게 다음 scope를 판정한다.

SCOPE_A_CLAUSE_INTERNAL

두 clause가 동일 neutral textual locus 내부에 있고,
후행 clause가 local syntactic dependency를 형성할 가능성이 높은 경우.

예:
- 동일 verse/unit 내부 InfC/relative/subordinate sequence
- local speech formula의 ויאמר clause 등

SCOPE_B_LOCAL_LOCUS_RELATION

인접하거나 가까운 서로 다른 clause bundles 사이의 관계지만
한 neutral textual locus의 내부/경계에 집중되는 경우.

SCOPE_C_CROSS_LOCUS_RELATION

서로 다른 neutral textual loci 사이의 candidate relation.

SCOPE_D_MACRO_PROJECTION_CANDIDATE

pairwise evidence 하나만이 아니라
multi-clause context configuration까지 고려할 때
macro textual relation의 human review에 의미 있는 candidate.

SCOPE_E_EVIDENCE_ONLY_NOT_MACRO_PROJECTABLE

실제 clause relation으로는 의미가 있으나
macro textual unit relation으로 투사할 근거가 부족한 경우.

중요:
SCOPE_D를 자동 structural relation으로 생성하지 않는다.

==================================================
6. multi-clause context bundle 생성
==================================================

각 supported pair에 대해
preceding-side와 later-side의 문맥 bundle을 만든다.

최소:

- focal clause
- previous 3 clauses
- following 3 clauses

즉 기본 fixed window:

[-3, focal, +3]

단:
book boundary를 넘지 않는다.
raw domain/direct-speech boundary 정보를 보존한다.

추가로 다음 adaptive window도 병행한다.

A.
same verse complete clause bundle

B.
same direct-speech / narrative raw-domain run
단, human speech-unit judgment 사용 금지

C.
formula continuation window
예:
ויען X
ויאמר
등 실제 adjacent formula components

D.
up to next raw subject/participant configuration change
가능하면 descriptive field로만

fixed window와 adaptive window를 모두 보존하되
한쪽이 다른 쪽을 overwrite하지 않는다.

7. context signature
==================================================

각 side의 context bundle에 다음 ordered signature를 생성한다.

CLAUSE_SEQUENCE:
- clause type sequence

VERB_SEQUENCE:
- main verb lexeme sequence
- stem/form sequence

SUBJECT_SEQUENCE:
- explicit subject lexeme/name sequence
- implicit subject markers

PHRASE_SEQUENCE:
- constituent-order signatures
- Time / Location presence
- Subject / Predicate / Object / Complement layout

DOMAIN_SEQUENCE:
- raw BHSA domain sequence

FORMULA_SEQUENCE:
- CSF-like formula atoms
- Wayhi/WayX/WXQt etc.
- repeated speech formula components

PARTICIPANT_SEQUENCE:
- explicit participant surfaces
- raw reference continuity flags
- participant-set change flags

TEMPORAL_LOCATIVE_SEQUENCE:
- temporal expressions
- locative expressions

중요:
이 signature는 human structure를 포함하지 않는다.

9. multi-clause pattern의 exact / partial correspondence
==================================================

정확한 rule bundle을 명문화한다.

예:

EXACT_CONFIGURATION_CORRESPONDENCE
=
focal + ordered following pattern이 모두 동일/호환

PARTIAL_CONFIGURATION_CORRESPONDENCE
=
focal은 강하게 대응하지만
후속 configuration 일부만 대응

FOCAL_ONLY_CORRESPONDENCE
=
focal clause/formula만 대응하고
surrounding configuration은 다름

CONFIGURATION_CONTRAST
=
focal correspondence가 존재하지만
후속/선행 배열이 구조적으로 뚜렷하게 다름

NO_CONTEXTUAL_CORRESPONDENCE
=
pairwise candidate는 있었으나
context bundle에서 반복 configuration을 찾지 못함

이 label은 여전히 candidate evidence classification이다.

human structural judgment 아님.

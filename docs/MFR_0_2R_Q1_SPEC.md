## Separation and coverage

Every frozen raw pair survives in an identity/hash crosswalk and qualification
table. Only QUALIFIED_DIRECT, QUALIFIED_UNIT_MEDIATED and
QUALIFIED_CONFIGURATION enter the new relation universe. SEARCH_ONLY,
EVIDENCE_ONLY, BLOCKED_BY_CONTEXT and UNRESOLVED are preserved separately.
An unqualified relation is not a demonstrated NO_RELATION outcome.

Source adapters currently implement four observable witness families:

- SB01: exact native dependent/head membership and a frozen subordinate-relation
  annotation. Native NA links never establish this dependency.
- SB03: an exact target-to-word native dependency with an explicit syntactic
  dependency path from the proposed source-containing unit opening to that word's
  containing clause. All such paths are retained; no distance limit applies.
- SB04: explicit secondary-participant mention recurrence in an immediately
  native-linked pair. The native edge is a required, dependent witness. This is
  an active context claim, not referential identity resolution.
- SB06: a repeated contiguous native-linked multi-clause configuration, with an
  explicit lexical NP in corresponding grammatical position and a non-speech
  predicate beyond a bare speech formula. The complete lexical/morphological
  and phrase-function sequence must correspond. This is
  a conservative executable subset, not a universal definition of configuration.
  NA links here document database sequence, not accepted mother relations.

These adapter criteria are GENERALIZED_FOR_MILAL. Other allowed SB mechanisms
remain unsupported/unresolved when no verified source adapter exists. No generic
similarity, lexical recurrence, PnG match, domain flag, corpus analogy, prosody or
conditional larger-unit membership can replace a witnessed connection. Missing
mechanism coverage is reported explicitly; technical gates do not certify
coverage completeness or methodological acceptance. Overrestrictive fixture
results withhold H0.1 readiness.

W-A01 requires a syntactic/reference binding; W-P01 requires independently
witnessed configuration and textual-line correspondence; W-H01 requires an
active bound participant context. Frozen Jin and Walton match definitions remain
unchanged. Each match is separately audited YES/NO for Q1 source binding.
Participant referential identity remains UNRESOLVED throughout.

Clause-binding issues are deferred before qualification. All raw atom IDs and
the original binding candidates remain available in the frozen upstream source.
No scores, weights, top-N selection or distance thresholds are used.

## Outcomes and confirmed symbolic-variant semantics

Exact source/target/relation/level effect defines one structural outcome group.
All rule and witness paths remain attached. Different qualified sources remain
different outcomes. Rule counts never become outcome competition counts.

The researcher confirmed on 2026-09-25:
UNSELECTED = UNDECIDED, not NO_RELATION. A selected edge versus an unselected
edge is not a pivot. Distinct positive mother, peer or relation assignments in
two coherent variants are pivots. A separately constrained explicit NO_RELATION
or EXCLUDED outcome could also compete, but Q1 does not invent one.
Differences solely in provenance, support, membership or UNDECIDED are not pivots.
GLOBAL_VARIANT_DIFFERENCE is distinct from TARGET_DECISION_PIVOT.

Under the frozen ANY_SUBSET_SATISFYING_CONSTRAINTS semantics, each individual
qualified edge is checked as a coherent hypothetical assignment, with all other
edges UNDECIDED. Two distinct positive assignments for a target provide concrete
pivot witnesses. Component size does not enter this calculation. This does not
choose a maximal, complete, accepted or canonical hierarchy.

## Execution and reporting

Blind qualification is frozen before controls or historical decisions are read.
External control source observations are limited to the existing fixture clause
IDs. The original 13 MFR.0.2A decisions are preserved exactly in a post-freeze
audit; evidence status may change without changing the human judgment.

The numbered 01–20 outputs, metadata and manifest are required. Additional
witness, freeze, source-receipt and gate-measurement tables make computations
inspectable. The exact upstream ZIPs remain required for lossless raw lookup.
Large input/output ZIPs and run directories remain outside Git.

Validation includes specification controls S1–S15, actual source-node negative
tests, output/receipt mutations for all 32 gates, full regression with zero skips,
self-test review, independent real executions and byte/manifest/ZIP verification.
Only a fully validated technical result can be committed/pushed. H0.1 is never
started automatically; overrestrictive controls require methodological review.

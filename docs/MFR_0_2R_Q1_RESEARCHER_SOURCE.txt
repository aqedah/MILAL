==================================================
0. 핵심 진단
==================================================

현재 일부 Walton-derived candidate rules는
candidate discovery에는 적절하지만
relation instantiation에는 너무 넓게 작동할 수 있다.

특히 다음을 감사한다:

W-A01
Walton explicit subordination candidate

W-P01
Walton same-clause-type parataxis prior

W-H01
Walton same-type participant-continuation hypotaxis candidate

중요:

이 규칙들을 삭제하지 않는다.

Walton source provenance도 유지한다.

다만 이 규칙이:

A.
SEARCH / PRIOR EVIDENCE를 생성하는가

또는

B.
특정 source-target pair의
STRUCTURALLY PLAUSIBLE RELATION을 생성하는가

를 분리한다.

==================================================
1. Three candidate stages
==================================================

모든 pair는 다음 단계를 구분할 수 있어야 한다.

STAGE 1:
SEARCH_CANDIDATE

넓은 corpus/index search에서 발견된 source-target pair.

STAGE 2:
SOURCE_BOUND_RELATION_CANDIDATE

source와 target 사이에
실제 relation을 지지하는 source-binding evidence가 있음.

STAGE 3:
HUMAN_ADJUDICATION_CANDIDATE

서로 다른 structural outcomes가 실제로 경쟁하여
사람의 판단이 필요한 경우.

이번 Q1은 주로 STAGE 1 → STAGE 2를 다룬다.

H0.1은 이후 STAGE 2 → STAGE 3를 다룬다.

==================================================
2. Do not reduce raw search universe
==================================================

기존 1,049,504 candidate universe를 삭제하거나 수정하지 않는다.

모든 기존 search candidate는 그대로 보존한다.

새 crosswalk를 생성:

candidate_id
search_candidate_status
relation_candidate_qualification
qualification_reason
disqualification_reason

기존 candidate universe row count는 동일해야 한다.

==================================================
3. Source-binding principle
==================================================

relation candidate가 되려면:

target feature

뿐 아니라

source-target 연결 증거

가 있어야 한다.

잘못된 예:

Target이 explicit subordinate clause다.
→ 모든 앞 절이 hypotactic mother candidate

금지.

Target이 source와 같은 clause type이다.
→ 모든 앞의 same-type clause가 parallel candidate

금지.

같은 participant가 먼 곳에서 다시 나타난다.
→ 해당 모든 절이 mother candidate

금지.

==================================================
4. Source-binding evidence categories
==================================================

SOURCE_BOUND_RELATION_CANDIDATE가 되려면
최소 하나 이상의 source-binding mechanism이 명시되어야 한다.

Allowed mechanisms:

SB01
DIRECT_SYNTACTIC_DEPENDENCY

SB02
EXPLICIT_REFERENCE_TO_SOURCE

SB03
REFERENCE_TO_SOURCE_CONTAINING_UNIT

SB04
PARTICIPANT_CONTINUATION_FROM_ACTIVE_UNIT

SB05
VALENCY_DEPENDENCY

SB06
FORMAL_CONFIGURATION_CORRESPONDENCE

SB07
TEMPORAL_DEPENDENCY

SB08
LOCATIVE_FRAME_DEPENDENCY

SB09
DOMAIN_CONTINUATION_OR_EMBEDDING

SB10
LEXICAL_ANAPHORIC_DEPENDENCY

SB11
ESTABLISHED_PARALLEL_CONFIGURATION

SB12
GLOBAL_CONFIGURATION_CONSTRAINT

중요:

단순 occurrence similarity는 source binding이 아니다.

==================================================
5. Direct versus indirect binding
==================================================

각 source-binding mechanism은 구분한다.

DIRECT_BINDING

예:
- subordinate marker가 바로 preceding finite clause에 의존
- suffix/pronoun이 source constituent를 직접 참조
- valency slot이 source-target 구조를 직접 묶음

UNIT_MEDIATED_BINDING

예:
- target reference가 source clause 자체가 아니라
  source가 여는 containing unit 내부 participant를 참조
- Bosman larger-unit case

CONFIGURATION_BINDING

예:
- repeated multi-clause configuration에서
  source와 target이 대응 위치를 차지
- Jin global structure example

==================================================
6. W-A01 qualification
==================================================

W-A01:
Walton §2.1.1.1
explicit subordinating features.

현재 rule provenance는 보존한다.

그러나:

explicit subordinator가 target에 존재한다는 사실만으로
arbitrary preceding source와 HYPOTACTIC relation을 만들지 않는다.

W-A01은 기본적으로:

EXPLICIT_SUBORDINATION_SEARCH_SIGNAL

을 생성한다.

HYPOTACTIC relation candidate로 승격하려면
source가 다음 중 하나를 만족해야 한다.

A.
immediately preceding syntactically eligible clause

B.
current active mother candidate in dependency chain

C.
target subordinate element가 source의 predicate /
constituent / participant를 직접 참조

D.
source containing unit에 대한
unit-mediated syntactic/reference dependency

E.
명시적으로 검증 가능한 non-local dependency

Important:

nearest clause is not automatically mother.

그러나:

“nearest is automatic이 아니다”

를

“모든 과거 clause가 동등한 mother candidate다”

로 해석하지 않는다.

==================================================
7. W-A01 intervening-context check
==================================================

non-adjacent W-A01 candidate는 반드시:

intervening_context_status

를 가진다.

Possible:

NO_STRUCTURAL_BREAK_DETECTED
ACTIVE_DEPENDENCY_CONTINUES
REFERENCE_CROSSES_INTERVENING_MATERIAL
INTERVENING_MATERIAL_BLOCKS_RELATION
UNKNOWN

Non-local W-A01 candidate가 유지되려면
장거리 연결을 설명하는 positive binding evidence가 필요하다.

Distance 자체는 금지조건이 아니다.

==================================================
8. W-P01 qualification
==================================================

W-P01:
Walton §2.1.2.1
same clause type → parataxis prior.

중요:

W-P01은 HARD RELATION RULE이 아니다.

따라서 기본 상태를:

SAME_TYPE_PARATAXIS_PRIOR_EVIDENCE

로 둔다.

same clause type만으로:

PARATACTIC relation candidate를 생성하지 않는다.

PARATACTIC으로 승격하려면
독립적인 correspondence가 더 필요하다.

예:

- same participant configuration
- explicit participant reintroduction
- lexical/formula correspondence
- phrase arrangement correspondence
- same discourse line
- temporal/frame correspondence
- repeated multi-clause configuration
- shared higher-level structural function

그리고:

source-target가 실제 같은 textual line에 놓일
positive evidence가 있어야 한다.

==================================================
9. W-P01 long-distance handling
==================================================

long-distance same-type clause는
same type만으로 relation candidate가 아니다.

Possible status:

SEARCH_CANDIDATE_SAME_TYPE_ONLY

추가 독립 증거가 있으면:

SOURCE_BOUND_PARATACTIC_CANDIDATE

중요:

same-type relation을 너무 좁히지 않는다.

Walton의 실제 장거리 correspondence 사례와
Jin의 long-distance parallel relations은
positive configuration evidence가 있으면 유지한다.

==================================================
10. W-H01 qualification
==================================================

W-H01:
same clause type +
continued secondary participant
→ hypotaxis candidate.

단순 participant recurrence와
participant continuation을 구분한다.

RECURRENCE:
본문 어디선가 같은 participant가 다시 등장.

CONTINUATION:
현재 활성화된 participant configuration 또는
source containing unit에서 이어짐.

W-H01 relation candidate로 승격하려면:

- participant is ACTIVE / CONTINUED
or
- participant is explicitly REINTRODUCED with source binding

그리고 최소 하나:

reference continuity
domain continuity
lexical continuity
syntactic correspondence
containing-unit continuity

가 있어야 한다.

본문 수십 장 전 동일 인물 등장만으로
HYPOTACTIC relation을 만들지 않는다.

21. Variant membership correction
==================================================

Do NOT classify relation as review-relevant merely because
it belongs to a variant component.

Distinguish:

VARIANT_MEMBER

from

VARIANT_DECISION_PIVOT

Definition:

VARIANT_MEMBER:
belongs to ambiguity component.

VARIANT_DECISION_PIVOT:
different coherent variants assign this target
different structural outcomes.

Only the latter is potentially human-review relevant.

==================================================
22. Variant pivot computation
==================================================

For each target compare coherent variants.

If all variants produce the same:

mother
relation type
parallel peer
local textual placement

then:

VARIANT_MEMBER_NON_PIVOT

If at least two coherent variants differ in structural outcome:

VARIANT_DECISION_PIVOT

Do not use component size as decision criterion.

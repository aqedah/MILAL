==================================================
2. 두 hierarchy layer 정의
==================================================

--------------------------------------------------
A. STRICT_CLAUSE_HIERARCHY
--------------------------------------------------

적용 대상:

- 실제 BHSA clause / clause_atom
- mother clause ↔ daughter clause
- syntactic/form-to-function relation
- Jin §3.2.9의 parataxis/hypotaxis 판단

특징:

HYPOTACTIC daughter라면
exactly one mother.

판정 근거 예:

- explicit subordination marker
- relative clause
- infinitive dependency
- anaphoric syntactic dependency
- participant/reference dependency
- embedded narrative line
- clause-level form-to-function evidence

--------------------------------------------------
B. MACRO_TEXTUAL_HIERARCHY
--------------------------------------------------

적용 대상:

- clause_atom anchored textual units
- speech units
- paragraph-level units
- scene/frame-level units
- larger textual onset/containment relations

근거:

- repeated multi-clause configuration
- structural-function correspondence
- paragraph/speech framing
- distributional textual level
- macro onset/closure pattern
- human textual adjudication

중요:

MACRO_TEXTUAL_HIERARCHY
≠
STRICT_CLAUSE_HIERARCHY

한 relation이 macro level에서 유효하더라도
strict clause mother가 자동 확정되는 것은 아니다.

6. Layer classification proposal
==================================================

각 relation에 다음 중 하나를 제안한다.

RL1_STRICT_CLAUSE_HIERARCHY

조건 예:
- source/target이 실제 clause/clause_atom relation
- linguistic rationale가 local syntactic dependency
- macro structural function에 의존하지 않음

--------------------------------------------------

RL2_MACRO_TEXTUAL_HIERARCHY

조건 예:
- relation이 textual units / speech units / scenes 사이의 관계
- multi-clause configuration 또는 structural-function evidence 기반
- strict clause mother를 직접 증명하지 않음

--------------------------------------------------

RL3_STRICT_AND_MACRO_SUPPORTED

두 층에서 독립 evidence가 모두 존재.

중요:
한 relation ID를 그대로 두 층에 자동 복제하지 않는다.
human review 필요.

--------------------------------------------------

RL4_HISTORICAL_LABEL_MIXES_LAYERS

기존 relation label/rationale가
strict clause와 macro hierarchy를 명확히 분리하지 못함.

예:
CHILD_OF라고 저장되어 있으나
실제 rationale는 macro scene containment임.

--------------------------------------------------

RL5_NON_PARENT_HIERARCHICAL_PLACEMENT

예:
CONTINUES_WITHIN이 placement는 표현하지만
strict mother edge는 아님.

--------------------------------------------------

RL6_RELATION_LAYER_UNRESOLVED

현재 provenance로 분류 불가.

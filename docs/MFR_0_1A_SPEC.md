# MFR.0.1a — Marker Evidence Consolidation Before Human Adjudication

Authority: [exact researcher request](MFR_0_1A_RESEARCHER_SOURCE.txt).
Baseline: `86b739c6f1f3ebc4675588a3452edd09e99387fd`.
MFR.0.1 source and outputs remain frozen. This is a presentation/evidence stage,
not marker discovery, hierarchy construction or human adjudication.

## Input, isolation and freeze

Verify the exact MFR.0.1 release ZIP SHA256, CRC, complete manifest and 362 pinned
baseline file hashes. Extract only the nine blind tables 03–11 for each of the five
scopes. Separate consolidation processes enforce an exact read/import allowlist of
these tables, the frozen generic serializer and new consolidation code. All reads
are recorded as logical source IDs and SHA256; interpreter/stdlib startup is outside
the application input audit. No historical judgment, known-control table, BHSA
reload or previous structural code enters consolidation.

Each process exits before its generated tables are physically frozen by manifest.
All five freezes precede known-control loading and rendering. Frozen bytes are
checked again afterward. The original upstream ZIP is preserved byte-for-byte,
including opaque historical members that consolidation never parses.

## Bundles, lattice and profiles

Canonical sorted exact marker-ID sets define bundles. Distinct sets never merge
by text similarity. IDs follow sorted occurrence sets. Each bundle preserves every
contributing family ID, type, signature resolution, construction definition and
complete original family record. Multiple family types give MULTI_RESOLUTION_BUNDLE;
one representation gives SINGLE_RESOLUTION_BUNDLE. Descriptive categories do not rank.

Repeated means at least two distinct marker occurrences in the bundle. A singleton
is explicit exactly when its frozen marker has nonempty `formal_explicitness`;
otherwise it is generic. This deliberately retains MFR.0.1's broad explicitness
semantics, including explicit configuration shifts. It does not redefine discovery
or equate singleton bundles with MFR.0.1 slot-repeat singleton counts.

The limited set lattice uses an inverted shared-marker index. This linguistic
connection supports subset, superset and partial overlap; exact-set multi-family
views are represented as SAME_OCCURRENCE_SET within their one bundle. Disjoint
sets are not falsely assigned an allowed overlap relation. A separate base-
construction index records observed Time/Loca variant differences, including
disjoint bundles sharing a base. Added/removed feature fields contain full observed
variant configurations. Stable ID order determines direction, never hierarchy.
This is limited evidence, not a claim of a complete theoretical family lattice.

Profiles preserve each marker, all seven family-type memberships, all seven clause
signature definitions with original values, explicit/repeated evidence, context,
force record, coverage/nested IDs and raw relation IDs. Whole observation/atom-
signature bytes remain unchanged in the input ZIP. Default family review includes
repeated, explicit, relation-participating or observed expansion-member bundles.
Other generic singletons remain ARCHIVE_FOR_REFERENCE, never invalidated.

## Relation and closure semantics

Cases use exact oriented source/target marker IDs. All raw relation IDs and labels
are retained; buckets overlap without a primary bucket. Hierarchy possibilities
remain candidates. Resumption enters default review only with an actual true frozen
resumption-evidence flag, not a shared lexical list alone. Formal-only cases enter
default review only for a shared expansion family with observed variation, or a
shared repeated multi-clause family. Other formal/insufficient cases stay archived.

Cessation occurrence is separate from a closure-target link. Evidence dimensions:

- Onset form: frozen speech, open-mouth, add/proverb, temporal-be, divine-speech,
  heading, after-death or first-year construction tags. These are linguistic tags.
- Coverage end: a source coverage ends at the target sequence position and one of
  its explicit atom IDs. Original end basis is retained.
- Formal family: shared exact, slot or multi-clause family, not a generic adjunct.
- Participant: literal surface intersection across explicit participant-bearing
  clauses in the source-to-target span, requiring more than one such clause.
  This is not resolved identity or inferred coreference.
- Domain: every clause in the span has a known compatible raw domain.
- Nested: the target is the terminal marker of an ending raw nested interval.

Coverage/formal links respectively yield their descriptive statuses. Structural
linking requires onset form plus participant, compatible domain or terminal nested
evidence. Multiple supported types coexist. A cessation pair lacking these linking
conditions is weak; a non-cessation target is insufficient. No closure is selected.

MFR.0.1 generated coverage endpoints mechanically at the next explicit cessation.
Thus a coverage-linked row may contain no independent linguistic corroboration.
The requested coverage-end criterion is applied literally, with this provenance
visible. Real Job's 963 raw closure pairs all have that endpoint and therefore all
remain reviewable under this contract. No desired reduction percentage overrides
the evidence or silently strengthens the criterion. The synthetic 100-pair case
separately proves that 99 unsupported pairs remain archived and one linked pair
is reviewable when only that pair has coverage evidence.

## Human representation and traceability

The packet uses bundle and relation cases, not 5,717 family headings. It includes
Hebrew surfaces, references, distinct definitions, adjunct/context variation and
case evidence. Marker pages show context, readable coverage alternatives, complete
nested marker membership and original signature/force evidence. Case IDs and raw
crosswalks connect every archived or default case to machine-readable evidence.

Canonical REVIEW_FIELDS are imported only by the post-freeze renderer. Additional
requested family/relation fields are added without duplicating the canonical schema.
Only review_status=UNREVIEWED is filled. No new human judgment, accepted family,
relation, closure, parent, tree or participant arc is generated.

## Validation and release

Synthetic scenarios S1–S12 and negative mutations cover every gate definition.
The 27 core gates run for all five corpora; 14 package gates cover baseline,
integrity, input separation, freeze chronology, controls and human-field discipline.
Three external release gates require full regression, skip zero and byte-identical
independent ZIPs. All generated and upstream manifests are verified separately.
Counts are measured, with only frozen Job totals used as optional input assertions.
Every known reference is consulted after five consolidation freezes; non-recovery
is preserved, including Job 37:24. Controls preserve all original labels and
cross-book cases without forcing Jin placement or a single relation.

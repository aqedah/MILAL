[추가 지시 — Bosman integration / poetry-aware evidence architecture]

현재 진행 중인 MFR.0.2R 작업을 중단하거나 처음부터 재시작하지 마세요.
기존 MFR.0.2R 본지시와 Walton 추가 지시를 유지한 상태에서
아래 요구사항을 현재 relation-engine 및 evidence architecture에 추가 통합하세요.

참고 연구:

Hendrik-Jan Bosman,
Prosodic Influence on the Text Syntax of Lamentations
(PhD dissertation, Vrije Universiteit Amsterdam, 2019).

주요 참조 부분:

- Chapter 9, especially §9.1
  Participant References and Syntactic Units
- Chapter 12, especially §12.1
  Conclusions from the Research
- Chapter 13
  Proposal for an Approach
- §13.1 General Outline
- §13.2 Organize Observations into Categories
- §13.3 Expand the Database
- §13.4 Add Linguistic Features to the Data
- §13.5 From Labels to Linguistic Rules
- Appendix A implementation discussion

중요:

MILAL은 Bosman의 애가 분석 전체를 구현하지 않습니다.

특히 다음을 그대로 일반화하지 마세요:

- Lamentations-specific acrostic rules
- specific colon / verseline / strophe judgments
- qinah assumptions
- Bosman의 개별 애가 hierarchy
- 특정 prosodic 분석을 Job에 hard-code하는 것

Bosman에게서 선택적으로 수용할 것은:

1. clause pair만이 아니라 larger textual-unit context를 고려하는 원칙
2. syntactic / participant-reference / prosodic evidence를 별도 layer로 관리하는 원칙
3. participant-reference structure가 syntactic hierarchy와 일치하지 않을 수 있다는 원칙
4. poetic/prosodic structure가 일부 clause relations에 실제 영향을 줄 가능성을 검증하는 원칙
5. program proposal과 human acceptance/rejection을 모두 보존하는 원칙
6. accepted뿐 아니라 rejected candidate도 linguistic-rule discovery에 사용하는 원칙
7. expandable, human-readable descriptive labels
8. multiple evidence categories의 결합을 숨기지 않고 보존하는 원칙
9. hypothesis → computation → human correction → revised rule의 iterative workflow

==================================================
B2. Multi-layer architecture
==================================================

Bosman의 중요한 제안을 반영하여
다음 구조들을 개념적으로 분리하세요.

A. TEXTUAL_SYNTACTIC_LAYER

- clause / clause_atom relations
- HYPOTACTIC
- PARATACTIC
- hierarchy candidate
- textual-unit containment

B. PARTICIPANT_REFERENCE_LAYER

- participant introductions
- reintroductions
- continuations
- pronouns
- suffixes
- implicit subject references
- participant sets
- speaker / addressee
- communication-domain continuity/change
- antecedent relations

C. POETIC_PROSODIC_LAYER

Job에서 BHSA 및 현재 자료로 관찰 가능한 범위만:

- poetic line / parallel configuration if available
- lexical parallelism
- syntactic parallelism
- repeated phrase configuration
- cola / verse-line information only if a reliable source is available
- closure/opening correspondence
- poetic arrangement evidence

중요:

이 세 layer는 서로 비교할 수 있어야 하지만
처음부터 하나의 hierarchy로 합치지 마세요.

==================================================
B3. Textual hierarchy remains distinct
==================================================

TEXTUAL_SYNTACTIC_LAYER의 mother-daughter hierarchy와

PARTICIPANT_REFERENCE_LAYER의 reference relation,

POETIC_PROSODIC_LAYER의 parallel / correspondence relation

을 동일한 edge type으로 처리하지 마세요.

Example:

Clause B may be syntactically dependent on Clause A

while a suffix in Clause B refers to a participant introduced
inside the larger unit opened by Clause X.

이 경우:

syntactic mother = A

reference antecedent/context = X 또는 X-unit 내부 participant

가 동시에 가능해야 합니다.

==================================================
B4. Larger-unit-aware candidate context
==================================================

Bosman이 지적한 핵심 문제를 구현하세요:

participant reference의 antecedent가
candidate mother clause 자체에 나타나지 않고,
그 mother가 여는 더 큰 syntactic unit 내부에
나타날 수 있습니다.

따라서 candidate evaluation을:

SOURCE_CLAUSE
↔
TARGET_CLAUSE

pair만으로 제한하지 마세요.

추가 context:

SOURCE_CONTAINING_UNIT
TARGET_CONTAINING_UNIT
INTERVENING_UNIT
PARTICIPANT_REFERENTS_WITHIN_SOURCE_UNIT

를 사용할 수 있어야 합니다.

Minimum fields:

source_clause_id
target_clause_id

source_unit_candidate_id
target_unit_candidate_id

direct_reference_match
unit_internal_reference_match

antecedent_clause_id
antecedent_unit_id

reference_depth

reference_hidden_in_larger_unit = true/false

==================================================
B5. Unit-aware participant evidence
==================================================

PARTICIPANT evidence를 다음 두 단계로 분리하세요.

DIRECT_PAIR_EVIDENCE

- source clause participant
- target clause participant
- direct suffix/pronoun antecedent

LARGER_UNIT_EVIDENCE

- participant introduced elsewhere inside source unit
- participant set active in source unit
- participant reintroduced in target
- reference path crossing internal clauses

따라서:

NO_PARTICIPANT_MATCH_AT_MOTHER_CLAUSE

가 곧

NO_PARTICIPANT_RELATION

을 의미하지 않도록 하세요.

B6. Intermediate textual units
==================================================

Bosman은 clause hierarchy가
clause / sentence / paragraph 사이에 존재하는
중간 textual units를 암시한다고 봅니다.

MILAL에서는 이를 provisional하게 표현하세요.

Possible object:

TEXTUAL_UNIT_CANDIDATE

fields:

unit_id
opening_clause
closing_clause_candidate
member_clauses
hierarchy_depth_candidate
parent_unit_candidate
derivation_source

derivation_source:

HIERARCHY_DERIVED
RELATION_COMPONENT_DERIVED
HUMAN_DEFINED

Do NOT invent literary paragraphs at this stage.

These are syntactically derived candidate units.

==================================================
B7. Poetry-aware analysis
==================================================

Job 3–42 contains extensive poetic discourse.

Therefore relation grammar developed mainly from prose examples
must not be assumed to explain every Job relation without residue.

Introduce:

POETRY_AWARE_EXCEPTION_CANDIDATE

when:

- normal syntactic rule generates an implausible relation
- strong poetic correspondence crosses the expected short-range relation
- parallel clause configuration conflicts with ordinary prose expectation
- constituent order may plausibly be affected by poetic arrangement
- repeated poetic structure provides competing evidence

However:

POETRY_AWARE_EXCEPTION_CANDIDATE
≠
automatic override of syntax

The evidence must be formally observable.

==================================================
B8. Syntax first, but not syntax only
==================================================

Maintain methodological order:

PASS 1
syntactic / morphological / participant / reference / time / location / domain

PASS 2
poetic/prosodic observations where relevant

PASS 3
human comparison of competing structures

Do not use:

theme
literary impression
assumed stanza
commentary outline

to pre-generate textual hierarchy.

But do not suppress formally observable poetic/prosodic evidence
when it genuinely conflicts with ordinary syntactic expectations.

B11. Separate evidence categories
==================================================

Extend current evidence architecture so every candidate relation can expose:

SYNTACTIC_LABELS

PARTICIPANT_LABELS

TEMPORAL_LABELS

LOCATIVE_LABELS

DOMAIN_LABELS

LEXICAL_LABELS

B14. Program / human decision matrix
==================================================

Bosman explicitly distinguishes four logical outcomes
for a clause connection.

MILAL must preserve equivalent states.

Minimum:

PROGRAM_PROPOSED_HUMAN_ACCEPTED

PROGRAM_PROPOSED_HUMAN_REJECTED

PROGRAM_NOT_PROPOSED_HUMAN_ACCEPTED

PROGRAM_NOT_PROPOSED_HUMAN_REJECTED

Because MILAL may preserve multiple candidates,
also allow:

PROGRAM_PROPOSED_HUMAN_UNDECIDED

PROGRAM_PROPOSED_HUMAN_ALTERNATIVE_RETAINED

Never overwrite the program proposal after human review.

B20. Poetic structure may diverge from syntax
==================================================

Both relations must survive as different typed edges.

==================================================
B36. Final methodological goal
==================================================

The purpose of Bosman integration is NOT:

“make Job look like Lamentations.”

The purpose is:

prevent a prose-oriented pairwise clause-relation engine
from mistaking the limits of its own model
for properties of a poetic Biblical Hebrew text.

MILAL must therefore be able to say:

- syntax suggests relation A
- participant-reference structure suggests relation B
- poetic/prosodic structure supplies relation/evidence C
- all three are formally observable
- their disagreement is preserved
- textual hierarchy is adjudicated only after the disagreement is visible

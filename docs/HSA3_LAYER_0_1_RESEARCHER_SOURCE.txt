==================================================
3. 새 parentage-necessity classification
==================================================

각 57개 unresolved row에 대해
기존 판단을 변경하지 않고 다음 review category 중 하나를
machine-generated audit proposal로 부여한다.

중요:
이는 HUMAN JUDGMENT가 아니다.
proposal_status = UNREVIEWED 이어야 한다.

권장 category:

P1_GENUINE_TEXTUAL_PARENTAGE_QUESTION

의미:
현재까지 확보된 relation/grouping만으로는
textual hierarchy상의 direct attachment 문제가 실제로 남아 있다.

P2_DIRECT_PARENT_NOT_REQUIRED_NON_TEXTUAL_GROUP

의미:
node 자체가 composition/grouping technical node이므로
textual parent를 가져야 한다는 요구가 잘못되었을 가능성이 높다.

예상 후보:
- CYCLE_1
- CYCLE_2
- CYCLE_3
- DIALOGUE_CYCLE_SEQUENCE
- ELIHU_SPEECH_SEQUENCE
- HUMAN_SCOPE_1_1_5
- HUMAN_SCOPE_2_1_10
- POST_DIALOGUE_JOB

단, hard-code하지 말고 실제 node type/schema를 확인한다.

P3_DIRECT_PARENT_NOT_REQUIRED_ROLE_ALIAS

의미:
동일 textual locus에 대한 별도 role alias이므로
별도 textual parent가 불필요할 가능성이 높다.

예상 historical category:
ROLE_ALIAS_OR_SAME_TEXTUAL_LOCUS

P4_LOCAL_RELATION_SUFFICIENT

의미:
CHILD_OF / CONTINUES_WITHIN / HIERARCHICALLY_ABOVE /
NO_BOUNDARY / closure 등 이미 accepted local relation이
필요한 textual structure를 충분히 제약한다.

추가 direct parent를 요구할 이유가 명확하지 않다.

P5_CONTAINER_MEMBERSHIP_SUFFICIENT

의미:
정확한 direct textual parent는 없지만,
accepted non-textual container membership과
same-level/function relations가 필요한 구조 정보를 이미 제공한다.

예:
개별 dialogue speech units within cycles,
Elihu speech units within ELIHU_SPEECH_SEQUENCE,
27:1 / 29:1 within POST_DIALOGUE_JOB 등.

P6_GLOBAL_LAYER_RELATION_SUFFICIENT

의미:
HSA3 global seam에서 composition / transition /
negative constraint로 관계가 충분히 판정되었으며
textual parent를 추가하는 것은 오히려 layer collapse가 될 수 있다.

P7_GENUINELY_UNRESOLVED_AFTER_LAYERED_REVIEW

의미:
layered structure를 모두 고려한 뒤에도
실제 textual direct-parent question이 남는다.

P1과 P7의 차이:
P1 = audit 시작 시 plausible genuine question
P7 = 모든 existing evidence/layers를 검토한 뒤에도
     실제로 인간 판정이 필요한 것으로 남은 final audit outcome.

가능하면 P1은 intermediate field로,
최종 추천은 P2–P7 중 하나로 둔다.

==================================================
4. 중요한 원칙
==================================================

다음 전제를 금지한다.

“Every structural node must have exactly one direct textual parent.”

MILAL은 이제 one-edge tree가 아니다.

따라서 다음은 정상적인 최종 상태일 수 있다.

- textual parent 없음
- composition membership 있음
- same-level relation 있음
- transition relation 있음
- overlay relation 있음

즉:

NO DIRECT TEXTUAL PARENT
≠
STRUCTURAL INFORMATION MISSING

이를 보고서의 핵심 방법론 문장으로 명시한다.

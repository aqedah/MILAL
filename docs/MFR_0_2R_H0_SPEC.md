# MFR.0.2R-H0 — Review eligibility without candidate deletion

Authority: [researcher request](MFR_0_2R_H0_RESEARCHER_SOURCE.txt).
Baseline: `3925b2b7a170dee2f2777941957a750248bfece8`.
Primary scope JOB; immutable MFR.0.2R ZIP SHA256:
`93ff58ba3f1498e5e93a4aaf23e15ceb777d54ef2704edf3c15fcffad9f05b7d`.

This additive stage consumes existing observations, matched rules, relations,
conflicts and variants. It never runs or changes relation/valency grammar,
chooses a mother, assigns a relation or supplies new human judgments.

## Eligibility semantics

Every original pair receives exactly one class. Precedence is RELATION_ELIGIBLE,
CONFIGURATION_ELIGIBLE, EVIDENCE_ONLY, INSUFFICIENT. Overlapping reasons remain
visible. Existing HYPOTACTIC/PARATACTIC/MULTIPLE and explicit unresolved relation
statuses qualify as relations. Exact membership in existing conflicts/components
or poetry/syntax exception records qualifies as configuration participation.
Observational correspondence alone qualifies only as evidence. Counterevidence
alone does not create a positive hierarchy proposal. Distance never excludes.

MFR.0.2A configuration identities are not themselves linguistic evidence. The
13 decisions are loaded only after the current-evidence crosswalk is frozen,
then mark Tier 1 target scope. Their direct existing global conflicts are
included; no transitive expansion through a whole symbolic component occurs.
Configuration judgments never turn every constituent pair into a mother/peer.
No legacy HSA/JIN judgments are inputs to eligibility.

Clause-binding deferrals refer to raw atoms, not arbitrary clause pairs. Preserve
them in a separate queue with exact construction/atom identity and unresolved
target status. Do not promote every pair touching that target to relation-eligible.
Poetic exception candidates have their own unresolved queue. Strong reference
evidence is not invented from a threshold; only existing structural involvement
can promote it from evidence to configuration review.

Targets retain all 2,938 inventory identities, including targets with zero pairs.
Required targets satisfy the requested competition/conflict/variant/revalidation/
binding criteria. Other eligible targets are optional; others are archive-only.
Tier 1 is explicit provisional revalidation/direct conflict scope; remaining
required targets are Tier 2, and remaining optional targets Tier 3.

## Presentation and traceability

Each eligible source-target pair has one card preserving every matched rule and
source contribution. Ten cards per page is navigation only: every page and every
eligible candidate remains in the manifest. No top-N truncation, scores, weighted
ranking or distance threshold is used. Source-node order is not preference.
The 13-case packet supplies historical context and complete target-page links;
it does not inline hundreds of full cards. Tier CSVs contain blank human fields,
derived from the canonical REVIEW_FIELDS plus explicitly requested H0 fields.

The full CSV crosswalk identifies every upstream pair, source/target, relation,
rule list, exact upstream table hash and canonical decoded-row hash. The upstream
ZIP, copied manifest and original physical member names support lossless lookup.
No large raw upstream tables are duplicated in the H0 ZIP. Original `.csv.gz`
members remain immutable. New H0 outputs use ordinary UTF-8 CSV/JSON/Markdown.

The disagreement matrix distinguishes Jin/Walton relation contributions from
Bosman/Oosting evidence. Mother and parallel candidate sets never select a member.
Global impact is qualitative and conditional, based on existing edges/conflicts.
Time/participant/reference competition flags require a cited matched-rule
predicate and actual competing relations, not mere occurrence.

## Controls, validation and readiness

Existing Pentateuch, Qohelet, Lamentations and Isaiah fixture checks are read
post-freeze; no corpus or external-book analysis is rerun. Every existing
fixture relation candidate must survive. Job validation references are solely
post-freeze reports and never enter eligibility logic.

Metrics report candidate and target populations, class/tier counts, medians,
maxima and reduction percentages. No numeric reduction pass threshold exists.
The configurable 90% required-target fraction interprets "nearly all" for the
diagnostic REVIEW_SIEVE_NOT_SELECTIVE warning only. It never changes eligibility
or decides a gate. Any warning is reported prominently and prevents unconditional
READY_FOR_MFR_0_2R_H declaration; it is not repaired by altering frozen grammar.

All 34 requested technical gates compute artifact/source/test invariants and
have negative tests. Validate syntax, stage tests, previous full regression and
synthetic packets before empirical A/B runs. Release requires matching manifests,
ZIP bytes, CRC/member hashes and all 34 gates. Human acceptance remains separate.

Next stage, only when authorized: MFR.0.2R-H, initially the 13 provisional cases.
No automatic resumption/closure adjudication or canonical hierarchy follows.

Pre-release empirical inspection found 92.55% of targets required. The initial
95% diagnostic was too narrow to signal that broad review burden. The final 90%
warning convention changes no eligibility, relation, tier or candidate count.
It is an advisory threshold, never a numerical pass requirement.
